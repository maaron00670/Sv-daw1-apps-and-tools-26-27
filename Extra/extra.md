# Extra

## Plan de estudiante de GitHub (GitHub Student Pack)

GitHub ofrece el **GitHub Student Developer Pack**, un conjunto de herramientas, servicios y beneficios gratuitos para estudiantes. Para poder solicitarlo, es necesario cumplir con los requisitos de elegibilidad y seguir el proceso de verificación.

### Recomendación previa

- **Usa tu cuenta personal de GitHub.** Es recomendable solicitar el Pack desde tu cuenta personal, no desde una cuenta compartida o creada exclusivamente para el centro.
- **Añade tu correo institucional como correo secundario.** Añade la dirección de correo que te proporcione el centro como correo secundario en tu cuenta de GitHub (Configuración → Emails). Esto te ayudará durante el proceso de verificación, aunque no es estrictamente obligatorio en todos los casos.

### Cómo solicitarlo

1. **Accede a la página oficial.** Ve a [education.github.com/pack](https://education.github.com/pack).
2. **Inicia la solicitud.** Pulsa "Get your pack" e inicia sesión con la cuenta de GitHub que deseas utilizar (preferiblemente tu cuenta personal).
3. **Completa el formulario.** Selecciona tu rol como "Student", indica tu centro educativo y el correo electrónico que vas a utilizar para la verificación. Si ya añadiste tu correo institucional como secundario, puedes seleccionarlo aquí.
4. **Verifica tu condición de estudiante.** GitHub te pedirá alguna prueba de que eres estudiante. Normalmente se solicita un documento válido (tarjeta de estudiante, matrícula, certificado de matrícula o documentación similar). Sube una imagen o PDF claro con tus datos visibles.
5. **Espera la revisión.** Una vez enviada la solicitud, el equipo de GitHub revisará la documentación. El proceso suele tardar desde unos minutos hasta unas horas, aunque en algunos casos puede demorar un poco más.
6. **Disfruta de los beneficios.** Cuando la solicitud sea aprobada, recibirás un correo de confirmación y podrás acceder a todos los beneficios del GitHub Student Developer Pack desde [education.github.com/pack](https://education.github.com/pack).

### Consejos

- **Usa una foto o escaneo legible.** Asegúrate de que el documento subido muestre claramente tu nombre, el nombre del centro, el curso/fecha o cualquier dato que acredite tu condición de estudiante.
- **Revisa el correo.** Mantén acceso al correo que uses para la verificación, ya que GitHub puede pedir aclaraciones o enviarte actualizaciones.
- **Renovación.** El Pack tiene validez mientras seas estudiante. Si cambia tu situación, es posible que debas volver a verificarte en el futuro.
- **Beneficios variados.** El Pack incluye créditos, herramientas de desarrollo, dominios, IDEs, servicios en la nube y mucho más. Puedes consultar la lista completa actualizada en la página oficial.
- **Paciencia:** Una vez se acepta el plan le costara unas 72 horas recibirlo desde que se aprovo
