## Plan de estudiante de GitHub (GitHub Student Pack)

GitHub ofrece el **GitHub Student Developer Pack**, un conjunto de herramientas, servicios y beneficios gratuitos para estudiantes. Para poder solicitarlo, es necesario cumplir con los requisitos de elegibilidad y seguir el proceso de verificación.

### Recomendación previa

- **Usa tu cuenta personal de GitHub.** Es recomendable solicitar el Pack desde tu cuenta personal, no desde una cuenta compartida o creada exclusivamente para el centro.
- **Añade tu correo institucional como correo secundario.** Añade la dirección de correo que te proporcione el centro como correo secundario en tu cuenta de GitHub (Configuración → Emails). Esto te ayudará durante el proceso de verificación, aunque no es estrictamente obligatorio en todos los casos.

### Cómo solicitarlo

1. **Accede a la página oficial.** Ve a [education.github.com/pack](https://education.github.com/pack).
2. **Inicia la solicitud.** Pulsa "Get your pack" e inicia sesión con la cuenta de GitHub que deseas utilizar (preferiblemente tu cuenta personal).
3. **Completa el formulario.** Selecciona tu rol como "Student", indica tu centro educativo y el correo electrónico que vas a utilizar para la verificación. Si ya añadiste tu correo institucional como secundario, puedes seleccionarlo aquí.
4. **Verifica tu condición de estudiante.** GitHub te pedirá alguna prueba de que eres estudiante. Normalmente se solicita un documento válido (tarjeta de estudiante, matrícula, certificado de matrícula o documentación similar). Sube una imagen o PDF claro con tus datos visibles.
5. **Espera la revisión.** Una vez enviada la solicitud, el equipo de GitHub revisará la documentación. El proceso suele tardar desde unos minutos hasta unas horas, aunque en algunos casos puede demorar un poco más.
6. **Disfruta de los beneficios.** Cuando la solicitud sea aprobada, recibirás un correo de confirmación y podrás acceder a todos los beneficios del GitHub Student Developer Pack desde [education.github.com/pack](https://education.github.com/pack).

### Consejos

- **Usa una foto o escaneo legible.** Asegúrate de que el documento subido muestre claramente tu nombre, el nombre del centro, el curso/fecha o cualquier dato que acredite tu condición de estudiante.
- **Revisa el correo.** Mantén acceso al correo que uses para la verificación, ya que GitHub puede pedir aclaraciones o enviarte actualizaciones.
- **Renovación.** El Pack tiene validez mientras seas estudiante. Si cambia tu situación, es posible que debas volver a verificarte en el futuro.
- **Beneficios variados.** El Pack incluye créditos, herramientas de desarrollo, dominios, IDEs, servicios en la nube y mucho más. Puedes consultar la lista completa actualizada en la página oficial.
- **Paciencia:** Una vez se acepta el plan le costara unas 72 horas recibirlo desde que se aprovo

## Páginas para estudiar y repasar

Recursos online para reforzar lo que se da en clase, practicar programación y repasar antes de los exámenes. Algunos tienen plan Pro o de pago, y varios de ellos se pueden conseguir gratis con el **GitHub Student Developer Pack** que se explica arriba.

### Cursos y práctica de programación

- **[Codédex](https://www.codedex.io/):** Plataforma de aprendizaje con cursos de Python, HTML, CSS, JavaScript, React, Git y GitHub, línea de comandos y más, todo con un enfoque muy práctico y gamificado. **Pro con el GitHub Student Pack:** incluye **6 meses gratis de Codédex Club**, la membresía premium.
- **[Codecademy](https://www.codecademy.com/):** Una de las plataformas más conocidas para aprender a programar desde cero, con cursos interactivos de desarrollo web, Python, JavaScript, SQL y mucho más. **Pro:** no está incluida en el GitHub Student Pack; tiene cursos gratuitos y el plan Pro se paga aparte.
- **[freeCodeCamp](https://www.freecodecamp.org/):** Plataforma totalmente gratuita con certificaciones de desarrollo web, JavaScript, Python y ciencia de datos. Ideal para practicar con proyectos reales. **Pro:** no tiene plan Pro ni hace falta el pack; todo el contenido es gratis.
- **[The Odin Project](https://www.theodinproject.com/):** Currículo completo y gratuito de desarrollo web de código abierto, con un enfoque muy práctico basado en proyectos y en aprender a buscar soluciones. **Pro:** no tiene plan Pro; es gratuito.
- **[Exercism](https://exercism.org/):** Ejercicios de programación con corrección y mentoría, disponibles en decenas de lenguajes. Muy útil para repasar lógica y practicar poco a poco. **Pro:** no tiene plan Pro; se mantiene con donaciones.
- **[FrontendMasters](https://frontendmasters.com/):** Cursos y talleres avanzados de JavaScript, Node.js y desarrollo frontend, impartidos por profesionales. **Pro con el GitHub Student Pack:** incluye **6 meses de acceso gratis** a todos los cursos y talleres.
- **[Scrimba](https://scrimba.com/):** Plataforma interactiva de aprendizaje frontend en la que puedes editar el código mientras ves las lecciones. **Pro con el GitHub Student Pack:** incluye **1 mes gratis de acceso Pro** con más de 40 cursos, proyectos y retos.
- **[Educative](https://www.educative.io/):** Cursos prácticos con entornos de código en el navegador, laboratorios y tutoriales guiados de desarrollo web, Python, Java y machine learning. **Pro con el GitHub Student Pack:** incluye **6 meses de acceso gratis** a más de 70 cursos y un **30 % de descuento** en cualquier suscripción.
- **[DataCamp](https://www.datacamp.com/):** Cursos interactivos de datos, Python, SQL, R y machine learning. **Pro con el GitHub Student Pack:** incluye **3 meses de acceso gratis** al suscribirte con tu cuenta de estudiante de GitHub.
- **[Boot.dev](https://www.boot.dev/):** Plataforma con enfoque de juego para aprender desarrollo backend, DevOps, Python, Go y TypeScript. **Pro con el GitHub Student Pack:** incluye **3 meses de acceso gratis** a la membresía interactiva completa.
- **[W3Schools](https://www.w3schools.com/):** Referencia clásica y muy directa para consultar HTML, CSS, JavaScript, SQL y otros lenguajes, con ejemplos que puedes probar al momento. **Pro:** no está incluida en el pack; el contenido principal es gratuito y los certificados se pagan aparte.
- **[LeetCode](https://leetcode.com/):** Retos de algoritmos y estructuras de datos, muy útiles para repasar lógica y preparar pruebas técnicas. **Pro:** no está incluido en el pack; el plan Premium se paga aparte.

### Documentación y referencia

- **[MDN Web Docs](https://developer.mozilla.org/es/):** La referencia oficial de HTML, CSS y JavaScript. Es la fuente más fiable para consultar cómo funciona una etiqueta, una propiedad o una API del navegador. **Pro:** no tiene plan Pro; es gratuita.
- **[DevDocs](https://devdocs.io/):** Reúne la documentación de muchísimas tecnologías en una sola web, con búsqueda rápida y sin anuncios. Perfecta para consultar mientras programas. **Pro:** no tiene plan Pro; es gratuita y de código abierto.
- **[dev.to](https://dev.to/):** Comunidad de desarrolladores con artículos, tutoriales y experiencias sobre programación y estudio. Útil para aprender de casos reales y ver cómo trabaja otra gente. **Pro:** no tiene plan Pro; es gratuita.

### Repaso y organización

- **[Anki](https://apps.ankiweb.net/):** Aplicación de tarjetas de memoria con repetición espaciada, ideal para memorizar sintaxis, comandos, conceptos y vocabulario. **Pro:** no tiene plan Pro; la versión de escritorio y la de Android son gratuitas (la de iOS se paga aparte).
- **[Quizlet](https://quizlet.com/):** Tarjetas y cuestionarios para repasar conceptos de forma rápida, solo o en grupo. **Pro:** no está incluido en el pack; tiene versión gratuita y un plan Plus de pago.
- **[Notion](https://www.notion.so/):** Espacio para organizar apuntes, listas de tareas, calendarios de estudio y resúmenes de asignaturas. **Pro con el GitHub Student Pack:** incluye el **plan Education gratis** con funciones extra de colaboración e IA.
- **[Obsidian](https://obsidian.md/):** Alternativa a Notion centrada en apuntes en Markdown guardados en tu propio ordenador, con enlaces entre notas, plugins y una vista de grafo para conectar ideas. Es muy buena para tener tus apuntes organizados sin depender de la nube. **Pro:** la aplicación es gratuita para uso personal y no está incluida en el GitHub Student Pack; sus servicios opcionales Sync y Publish tienen un **40 % de descuento para estudiantes** solicitándolo con el correo del centro.

> Los planes y duraciones de las ofertas pueden cambiar. Consulta siempre la lista actualizada en [education.github.com/pack](https://education.github.com/pack) antes de solicitarlas.
