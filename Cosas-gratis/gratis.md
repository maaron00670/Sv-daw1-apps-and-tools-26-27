### Aplicaciones de escritorio

- **[Pear Desktop](https://github.com/pear-devs/pear-desktop):** Cliente de escritorio no oficial para YouTube Music, de código abierto y disponible para Windows, macOS y Linux. Mantiene la interfaz de YouTube Music, pero añade integración con el escritorio, plugins, temas, descarga de canciones y bloqueo de anuncios. No está afiliado a Google ni a YouTube.

- **[Spicetify](https://spicetify.app/):** Herramienta de código abierto para personalizar el cliente oficial de Spotify en Windows, macOS y Linux. Permite instalar temas, extensiones y aplicaciones personalizadas (letras sincronizadas, estadísticas, controles extra...) desde su Marketplace. Modifica el cliente de Spotify, así que úsala bajo tu responsabilidad y revisa que siga siendo compatible después de cada actualización.

- **[ArtCraft](https://getartcraft.com/):** Suite de aplicaciones gratuitas y de código abierto que busca sustituir al paquete de Adobe: PhotoCraft (Photoshop), VectorCraft (Illustrator), FilmCraft (Premiere Pro), LightCraft (Lightroom), EffectCraft (After Effects), DesignCraft (InDesign) y PdfCraft (Acrobat), entre otras. Están escritas en Rust, funcionan en local y tienen versiones para Windows, macOS, Linux y, en algunos casos, navegador. Es un proyecto muy reciente y varias aplicaciones siguen en alpha o en desarrollo, así que conviene probarlo antes de usarlo para trabajos importantes.

### Repos de GitHub interesantes

- **[OmniRoute](https://github.com/diegosouzapw/OmniRoute):** Gateway de IA de código abierto (MIT) que reúne cientos de proveedores y modelos detrás de un único endpoint compatible con OpenAI. Incluye enrutado inteligente, fallback automático cuando un proveedor falla o se queda sin cuota, compresión de contexto y un panel local. Se puede usar con Claude Code, Codex, Cursor, OpenCode, Cline y otros clientes. Configura tus propias claves y respeta las condiciones de cada proveedor.

- **[Concat](https://github.com/jub0t/Concat):** Editor de vídeo gratuito, open source y local, planteado como alternativa a CapCut. Está disponible para Windows, macOS, Linux y Android, y cubre lo básico que se suele usar en CapCut: subtítulos automáticos, texto a voz, eliminación de fondo, animaciones con keyframes, efectos, multitrack y exportación hasta 4K, sin marca de agua, cuenta ni suscripción. Sigue en desarrollo y algunas versiones son alpha.
