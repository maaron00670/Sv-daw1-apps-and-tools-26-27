# Programación

## Entornos de desarrollo (IDE)

Actualmente, en la asignatura de Programación se trabaja con **Java**.

Esta sección recopila diferentes entornos de desarrollo que pueden utilizarse para programar, junto con alternativas de código abierto y otras opciones multiplataforma.

### Entornos principales

#### IntelliJ IDEA
Entorno de desarrollo de JetBrains orientado a Java, con herramientas de autocompletado, depuración y gestión de proyectos.

**Web oficial:** https://www.jetbrains.com/idea/

#### Visual Studio
Entorno de desarrollo de Microsoft con herramientas para programar en diferentes lenguajes.

**Nota:** No debe confundirse con Visual Studio Code, que es un editor de código independiente.

**Web oficial:** https://visualstudio.microsoft.com/

#### Google Antigravity
Entorno de desarrollo de Google centrado en la programación asistida por inteligencia artificial, con funciones para ayudar a escribir, modificar y revisar código.

**Web oficial:** https://antigravity.google/

### Alternativas y opciones de código abierto

#### IntelliJ IDEA Community Edition
Edición gratuita y de código abierto de IntelliJ IDEA, adecuada para trabajar con Java y desarrollar proyectos de programación.

**Web oficial:** https://www.jetbrains.com/idea/

#### VSCodium
Distribución comunitaria de Visual Studio Code que utiliza código abierto y elimina algunas personalizaciones y componentes específicos de Microsoft.

**Ventajas:** gratuito, extensible mediante extensiones y disponible para Windows, macOS y Linux.

**Desventajas:** puede requerir instalar extensiones adicionales y configurar el entorno para trabajar cómodamente con Java.

**Web oficial:** https://vscodium.com/

### Consideraciones

No es obligatorio utilizar un entorno de desarrollo concreto. Se puede trabajar con cualquier IDE o editor de código que permita realizar las tareas de la asignatura, siempre que se conozca su funcionamiento y se sepa configurar y utilizar correctamente.

La elección del entorno depende de las preferencias personales, el sistema operativo y las necesidades de cada proyecto.
